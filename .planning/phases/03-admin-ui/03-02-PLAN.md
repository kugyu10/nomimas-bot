<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → proxy.ts | 未認証リクエストの遮断点（セッション cookie 検証） |
| OAuth リダイレクト → /auth/callback | 認可コードがセッションに変換される地点 |
| npm install | サプライチェーン（公開レジストリからの取得） |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-SC | Tampering | npm installs（vitest [SUS] / postgres [ASSUMED]） | mitigate | install 前の自動正当性ゲート: repository.url が公式（vitest-dev/vitest, porsager/postgres）一致 + postinstall 空を必須化、不一致は abort（リサーチが registry 実査済み。postgres は既存プロジェクト依存と同一物・同バージョン pin） |
| T-03-06 | Spoofing | getSession() の user 信用 | mitigate | 保護判定は getClaims() のみ（RESEARCH Anti-Pattern 準拠） |
| T-03-07 | Information Disclosure | NEXT_PUBLIC ビルド焼き込み | mitigate | NEXT_PUBLIC は URL / publishable キー / AUTH_MOCK の 3 つ限定。`git grep service_role -- admin/` 0 件をタスク verify に組込 |
| T-03-08 | Tampering | proxy cookie 同期契約違反（ランダムログアウト） | mitigate | 公式コード原型維持 + 「supabaseResponse をそのまま返す」をソースアサーションで確認 |
| T-03-09 | Spoofing | OAuth open redirect（next パラメータ） | mitigate | callback の next は origin 相対パスのみ許可（先頭 '/' 検証）。uri_allow_list は localhost:3000/** 設定済み |
</threat_model>
