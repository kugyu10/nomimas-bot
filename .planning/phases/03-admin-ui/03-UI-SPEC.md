## Spacing Scale

Declared values (multiples of 4 only). Internal admin tool — compact scale is preferred.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gap, badge internal padding, table cell padding (horizontal) |
| sm | 8px | Button internal padding (vertical), form field gap, list item gap |
| md | 16px | Card body padding, sidebar item padding, section header margin-bottom |
| lg | 24px | Card-to-card gap, dialog content padding, form group gap |
| xl | 32px | Page content area horizontal padding, section breaks within a page |
| 2xl | 48px | Header height (fixed, sidebar-aware) |
| 3xl | 64px | Not used in this phase (no large hero sections) |

Exceptions:
- Sidebar width: 240px (shadcn SidebarProvider default). **(auto)**
- OA selector in header: 280px max-width combobox. **(auto)**
- Table row height: 40px (compact mode — `size="sm"` on shadcn Table). **(auto)**
- Combobox popover (manual linking): 320px width, max-height 280px with scroll. **(auto)**
- Touch target minimum: 44px height for all interactive buttons (accessibility). **(auto)**

## Typography

Font: Inter (via `next/font/google` or system-ui fallback). All weights from the same family.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 14px | 400 (regular) | 1.5 | Table cell content, form field values, description text |
| Label | 12px | 500 (medium) | 1.4 | Table column headers, form labels, badge text, tab labels |
| Heading | 20px | 600 (semibold) | 1.2 | Page titles (e.g., "イベント一覧"), dialog titles |
| Display | 28px | 700 (bold) | 1.1 | Not used in Phase 3 (no marketing/hero sections) |

Rules:
- Body and Label are the two production weights. Heading uses semibold (600) only. **(auto)**
- Japanese text: no letter-spacing adjustments needed at these sizes. **(auto)**
- Monospace (12px/400): used only in OA設定 for question JSON previews or API key display fields. **(auto)**

## Page-Level Layout Contract

### Overall Shell

```
┌──────────────────────────────────────────────────────┐
│ Header (48px fixed)                                  │
│  [sidebar toggle] [OA selector combobox] ... [user]  │
├────────────┬─────────────────────────────────────────┤
│  Sidebar   │  Main Content Area                      │
│  (240px)   │  padding: 24px                          │
│            │                                         │
│  イベント一覧│                                         │
│  OA設定    │                                         │
│            │                                         │
└────────────┴─────────────────────────────────────────┘
```

- Sidebar: shadcn `<Sidebar>` with `<SidebarProvider>`. Collapsible on mobile. **(auto)**
- Header: sticky top-0, z-50, bg-background, border-b. **(auto)**
- OA selector: `<Select>` or `<Combobox>` in header. Width 280px. Switching OA re-fetches all scoped data. **(auto)**
- Main content: `max-w-5xl mx-auto` for form-heavy pages; `w-full` for tables. **(auto)**

### イベント一覧 (`/events`)

- `<Table>` with columns: イベント名 | 開催日 | 参加者数 | 回答済み / 総数 | ステータス | 操作
- 操作列: "詳細" link button (size="sm"), no destructive action in this list view
- Empty state: "まだイベントがありません" + "イベントを作成" CTA button
- Page title: "イベント一覧" (heading 20px/600)
- Primary CTA: "+ イベントを作成" (accent button, top-right of page header)

### イベント作成 / 編集ダイアログ

- `<Dialog>` triggered from CTA. `<Form>` with react-hook-form + zod.
- Fields:
  - イベント名 (text, required)
  - 開催日 (date input, required)
  - 集合時刻 (time input, optional)
  - 場所 (text, optional)
  - 参加費 (number input, optional, suffix: "円")
  - 店情報 / 備考 (textarea, optional)
  - confirm_days_before (select: 1/2/3/5/7日前, default 3)
  - プラットフォームURL (repeatable input group: [プラットフォーム種別 select] + [URL input]; min 1, add button "+URL追加")
- Dialog footer: [キャンセル (ghost)] [保存 (accent)]

### イベント詳細 (`/events/[id]`)

- Page title: {イベント名} (20px/600) + 開催日 subtitle (14px/400 muted)
- 3 tabs: 参加者 | 回答状況 | 紐付け
- Below title, action area: "参加者を取得" button (outline, triggers scraper Edge Function)

#### 参加者タブ

- Table: Twipla参加者名 | Xアカウント | 取得日時 | 紐付けステータス (badge)
- Row actions: none (read-only in this tab)

#### 回答状況タブ

- Table: 参加者名 | LINE表示名 | Q1 | Q2 | Q3 | ... | 全体ステータス (badge)
- Each Qn cell shows the answer text (truncated at 20 chars, tooltip for full) or "—" if not answered
- 全体ステータス: badge using status color contract above
- Empty state: "まだ回答がありません" (no CTA — this is read-only)

#### 紐付けタブ

- Two-column layout (desktop): 左=未紐付け参加者リスト | 右=紐付け済みリスト
- 未紐付けリスト: participant名 + Combobox (LINE友だちを選択...) + "紐付け" button
- 紐付け済みリスト: participant名 → LINE表示名 + "解除" button (destructive/outline)
- Combobox: searches `line_users.display_name` + filters already-linked users
- Empty state (全員紐付け済み): "全員の紐付けが完了しています" (green alert variant)

### OA設定 (`/oa/settings`)

- Page title: "OA設定" (20px/600)
- Current OA name as subtitle (driven by header OA selector)
- Sections (Cards):
  1. 基本情報: OA名, チャンネルID (read-only display), 管理者TwitterID(s) (comma-separated input)
  2. 定型文: 最終確認メッセージ冒頭 (textarea), 完了メッセージ (textarea)
  3. 質問設定: ordered list of question items (text + drag handle for reorder). Add/remove per item.
- Page footer: "保存" button (accent, full-width on mobile, right-aligned on desktop)
- No destructive action on this page in Phase 3 (OA deletion deferred)

## Interaction Contracts

### OA Selector (Header)

- Switching OA triggers router.refresh() + re-fetch of all scoped data
- Currently selected OA persisted in localStorage key `nomimas_selected_oa_id`
- If stored OA ID no longer in user's authorized list → fall back to first OA in list
- Loading indicator: header OA selector shows spinner icon while scope is switching **(auto)**

### Manual Linking Combobox (紐付けタブ)

- Combobox opens on click of the LINE友だち input area
- Filters `line_users.display_name` client-side (list is small: typically < 200 entries)
- Already-linked `line_user_id` values are excluded from dropdown options
- On "紐付け" click: optimistic UI update (move participant to linked list) + server action call
- On server action failure: revert optimistic update + show error alert inline **(auto)**
- On "解除" click: open `<AlertDialog>` confirmation before server action

### 参加者を取得 (Scraper Trigger)

- Button becomes disabled + shows spinner while request is in-flight
- On success: table re-fetches + show inline alert: "参加者の取得が完了しました（{n}件）"
- On failure: show inline alert (error copy above)
- Button re-enables after response (success or error) **(auto)**

### イベント作成フォーム (Dialog)

- Real-time zod validation on blur for each field
- "保存" button disabled until form is valid
- プラットフォームURL: Twipla URL pattern validation (`https://twipla.jp/events/[0-9]+`)
- On save success: dialog closes + event list re-fetches + show alert: "イベントを作成しました"
- On save failure: dialog stays open + error displayed below form footer **(auto)**

### Authentication

- Unauthenticated requests → redirect to `/login`
- Login page: X OAuth button (primary) + mock login form (dev env only, hidden via `NEXT_PUBLIC_AUTH_MOCK=1`)
- Post-login redirect: back to original destination URL or `/events`
- Unauthorized OA access → 403 page with "このOAへのアクセス権限がありません" message **(auto)**
