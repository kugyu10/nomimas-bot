## Overview

Twiplaで参加表明したオフ会参加者にLINEで最終確認を自動配信し回答を収集するツールのv1。
最大リスク（Twiplaスクレイピング）をPhase 1で実証し、Phase 2でLINE Bot自動配信〜回答収集のE2E、
Phase 3でNext.js管理画面（モック差替可能なX OAuth・RLS実効）、Phase 4で通知・テンプレート・root権限・
実Twipla URL全鎖E2Eまでを夜間自律実行で完成させた。v1要件12件すべて機械検証済み。

## Milestone Summary

**Key Decisions:**
- 全スタックSupabase統一（Edge Functions + pg_cron、Lambda不要）/ cheerio（Twipla静的HTML）
- LINEアクセストークンはステートレスv3を実行時発行（長期トークン不保持）
- cron認証はVault参照 + x-cron-key（publicリポジトリでシークレット非コミット）
- 通知はイベント駆動（webhook/scraper発火・送信時2日前判定・notification_logsで機械検証）
- rootはroot_users + is_root()のSELECT専用OR拡張（書込は owner/co-owner のまま）
- スキーマ変更は既存マイグレーションin-place編集 + `db reset --linked`（dev使い捨て・ゼロから再現可能）
- 識別子: participants natural_key（screen_name優先）で同名participant衝突を解消

**Issues Resolved:**
- Twipla `a.card.namelist` セレクタの興味あり/不参加混入（member_listスコープで解決）
- IPv6限定DNSでの直接DB接続不可（linked + session pooler で解決）
- JST/UTCの往復シフト（Intl Asia/Tokyo で入出力両側固定）
- コードレビュー4フェーズ合計: Critical 3 + Warning 29 + Info多数を修正

**Issues Deferred:**
- HUMAN-UAT: 実LINE受信・実X OAuthブラウザ往復・実ブラウザ操作・Vercelデプロイ（各 *-HUMAN-UAT.md）
- prod環境構築チェックリスト（v1.0-MILESTONE-AUDIT.md）
- v2: LINK-01 / DATA-01 / REMIND-01、UIレビュー残置項目

**Final Verification:** 12/12要件 / integration_ok (11/11面) / Deno 105 + vitest 76 + RLS 121 + 全鎖E2E green
