## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| インターネット → webhook関数 | verify_jwt無効のため誰でも到達可能。署名検証が唯一の防壁 |
| Edge Function → LINE API | チャネルシークレットを用いたトークン発行 |
| ローカルCLI → Supabase secrets | シークレット投入時のシェル履歴・ログ露出 |
| リポジトリ(public) → 全世界 | テストコード・コミットへのシークレット混入 |
